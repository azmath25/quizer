## Current implementation

- `js/components/assistant.js` uses existing `sendTeacherChatMessage` from `js/services/mimo-chat.js` (the same production Firebase v2 callable, `mimoTeacherChat`, used by Problem Bank and Results Ask AI).
- Access requires resolved, active, email-verified Firebase session with the `teach` capability. Backend still checks teacher/admin role and quotas independently.
- A single chat request receives fresh `requestId` and no automatic retry; send button/composer are locked while pending. On uncertainty, the request reference is displayed; interrupted pending requests are marked uncertain on reload.
- Only successfully completed exchanges enter the last-eight-message bounded follow-up history. Errors, loading, local helper messages, and unconfirmed requests are excluded. Context is intentionally empty by default. Explicitly reviewed scissors-selected text can be pasted into the message and sent deliberately.
- Model replies use the same safe DOM Markdown and restricted local MathJax renderer as Ask AI. No raw model HTML execution.
- Per-teacher browser-session history uses `mathquiz.assistant.mimo.v1.<Firebase UID>`; switching teacher accounts unmounts and remounts the dock and invalidates in-flight results. The earlier demo cache is not reused.
- The existing draggable assistant toolbar, text/MathJax scissors tool and permissioned tab screenshot tool remain. **Files/screenshots are locally staged only** and blocked from text-chat submission, because the deployed callable does not accept binary inputs. UI no longer claims to extract an uploaded PDF. No fake problem batch/quiz handoff can be generated by this chat.
- Cache-busted the imported `assistant.js?v=17` and matching CSS to ensure published browsers load the new implementation.
